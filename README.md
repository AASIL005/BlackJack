🃏 Blackjack Game 🎮
A simple Blackjack (21) game built using Core JavaScript, HTML, and CSS — no libraries, no frameworks, just pure web development! Try your luck against the computer dealer and enjoy a fully interactive card game experience right in your browser.

🎯 Game Objective
Beat the dealer by getting a card total as close to 21 as possible without going over.

Face cards are worth 10

Aces can be 1 or 11

Player starts with 2 cards and can "Hit" (draw a new card) or "Stand" (hold their total)

Dealer must draw until they reach at least 17


🧰 Technologies Used
✅ HTML5

✅ CSS3

✅ Vanilla JavaScript (ES6+)

Double-click index.html or open it in any web browser.

✅ No installation or server setup required!
